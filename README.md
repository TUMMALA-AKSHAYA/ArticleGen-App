# ArticleGen – AI-Powered Article Generator 📝✨

ArticleGen is an AI-driven web application that generates full-length, well-structured articles from a single topic or headline. Built using **Python**, **LangChain**, and **OpenAI**, it allows users to input any subject and instantly receive an informative article suitable for blogs, reports, or essays.

---

## 🚀 Features

- ✏️ **Topic to Article**: Just input a title, and ArticleGen generates a structured article.
- 🤖 **Powered by LLMs**: Uses OpenAI’s language models with LangChain for prompt chaining.
- 🌐 **Web Interface**: User-friendly interface built using Flask (or Streamlit).
- 🔧 **Easily Extensible**: Can be improved with features like tone/style control, saving history, or PDF export.

---

## 🛠️ Tech Stack

- **Frontend**: HTML + CSS (or Streamlit if used)
- **Backend**: Python, Flask (or Streamlit)
- **AI Engine**: LangChain + OpenAI (can switch to any LLM)
- **Deployment**: Replit / Localhost / Render (optional)
